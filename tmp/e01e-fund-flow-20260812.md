# 0xE01e…5950 最近资金去向核验

核验地址：`0xE01ecFF2F6c4F2416E83e6861e8ABf79b1C95950`

数据截点：约 2026-08-12 01:16 JST。Blockscout 用于发现和分页，余额与关键事件另经 Ethereum RPC 复核。已剔除地址投毒、Unicode 假币、零金额污染记录。

## 结论

该地址余额下降不是单一原因：

1. 一部分资产通过 `0xa6Ae…F71D` 进入 Binance 充值/归集路线；
2. 一部分资产迁移到其他高度关联的 Aqua 做市钱包，尤其是 `0x619292…f8a3`；
3. `0x00f3…434a` 是短期调拨钱包，绝大部分资产又退回目标地址，并非提现；
4. 部分余额通过真实 Aqua fill 换成其他库存，不能把所有 Transfer 都看成主动转账；
5. `dock()` 只关闭虚拟策略，本身并不会把 ERC-20 转出钱包。

- 真正离开自托管链上集群的主要路线：`E01e → a6Ae → Binance 14`；
- 继续留在策略集群内的主要路线：`E01e → 456b → 619292`，以及 `E01e → F594`；
